## 5.0.2 — 2026-09-22

只影响测试与 CI，不影响运行时行为。已经发布的 5.0 / 5.0.1 产物不需要替换。

修复了 CI 里契约测试与集成测试共用数据库导致的断言冲突。

## 5.0.1 — 2026-09-22

只影响测试与 CI。修复了集成测试之间共享向量列维度导致的失败。

## 5.0 — 2026-09-22

没有新功能，是一次全面审查与修复。用户可见的变化包括：

- **升级前必须先跑 `make migrate-up`**：新增三条迁移（用量索引、枚举约束、保留期索引）。漏跑不会立刻报错，但用量表会随使用变慢。
- **移除 `CONGORAG_PORT`**：它此前从未生效，真正决定监听地址的是 `CONGORAG_LISTEN_ADDR`。Compose 里的同名变量是宿主机端口映射，不受影响。
- **聊天与 Agent 输入上限 8000 字符**：超限返回 `invalid_argument`，不写消息行。
- **JSON 端点 1 MiB 请求体上限**：超限返回 400，文案带上限值。上传仍走 `CONGORAG_MAX_UPLOAD_BYTES`。
- **服务端 5 分钟 ReadTimeout**：对 SSE 安全，读超时只管请求方向。
- **SSE 错误帧不再泄漏 5xx 内部错误原文**。
- **SSE 的 `id: 0` 不再出现在线路上**。
- **工具结果截断到 16 KiB**，并显式告诉模型结果被截断。

## 版本号

版本号是 `MAJOR.MINOR`，热修才出现 `MAJOR.MINOR.PATCH`。契约的 `info.version` 跟产品版本走，但兼容边界是路径里的 `/api/v1`。
