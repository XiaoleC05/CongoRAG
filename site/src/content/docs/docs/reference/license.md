CongoRAG 的代码使用 MIT 许可证。全文在仓库的 [LICENSE](https://github.com/XiaoleC05/CongoRAG/blob/main/LICENSE)。

你可以使用、复制、修改、合并、发布、分发、再授权和/或销售软件的副本，但要在副本里保留版权声明和许可声明。软件按“原样”提供，不附带担保。

## 依赖

项目依赖的第三方库各有自己的许可证。分发二进制或镜像时，要把对应的许可证和声明一起带上；具体以各依赖仓库为准。

这篇不是法律意见。要用于商业分发，建议让法务看一遍依赖清单。
