## 1. 作品名称

ConGoRAG 科研助手——可溯源、抗幻觉的论文阅读与写作工作台

## 2. 作品简介（约 400 字，可直接粘贴）

ConGoRAG 科研助手是一个可溯源、抗幻觉的论文阅读与写作工作台，面向研究生与科研人员的
文献精读与综述写作场景。作品在本人 MIT 开源项目 v5.0.2 基础上补齐科研学术层：PDF 由
Python 侧车解析到块级别（页码、归一化坐标、章节路径、OCR/表格），回答中的每条引用都能
点回原文第 N 页并高亮对应段落；检索采用"向量 + 中文 bigram 全文 + RRF 融合 + 近重复抑制"，
并给出融合/向量/词法三路分数；抗幻觉采用三道闸门（逐句引用提示词、grounding 引用落地检查、
无证据固定拒答）；在此之上提供论文阅读器（目录/整页翻译/参考文献）、arXiv 检索 Agent、
引用图谱与写作 Copilot（相关工作/摘要/提纲草稿，逐句引用可回链）。系统为 Go + React +
Python 三进程架构，OpenAPI 契约驱动，Docker Compose 一键部署，本地优先 + BYOK。
仓库：https://github.com/XiaoleC05/CongoRAG（分支 cup-2026）。
