## 三、5 分钟演示路径

1. **知识库 → PDF 学术解析验证**：文档状态/分块数（434/513/6 等）；
2. **检索调试**：输入"训练用了多少块 GPU"，看融合分/向量分/词法分与页码；
3. **对话 → 示例：引用溯源**：打开预置会话 → 悬停引用角标 →「在原文中查看」→ 阅读器第 7 页琥珀色 bbox；
4. **对话 → 示例：无证据拒答**：固定拒答 + 引用校验徽标；
5. **阅读器**：目录跳页 →「翻译本页」→ 参考文献（survey 的 [1] 可点）；
6. **写作 Copilot**：主题"Transformer 的注意力机制与训练效率"→ 生成「相关工作」；再演示 CSV 可视化；
7. **引用图谱**：知识库"引用图谱演示（survey → Attention）"→ 生成图谱/自动综述；
8. **Agent → arXiv 文献助手**：回放一次完成的运行（tool_call/tool_result），或现场检索；
9. **Prompt 审计 + Ctrl+K**：17 条提示词的版本/SHA-256/代码位置；命令面板跳转任意页面。

## 演示小提示

- 对话页有 3 类示例会话可直接打开，不受模型随机性影响；
- 现场提问若偶发"根据现有资料无法回答"，可换更完整的问法或直接看示例会话；这是模型对证据充分性的判断波动；
- 主入口首次打开若较慢，请稍等缓存。
