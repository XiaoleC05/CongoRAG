## 二、分镜与逐字稿

### 00:00–00:25 开场

**画面**：ConGoRAG 首页 → 知识库列表（深色工作台）。

**旁白**：
"读论文有三个绕不开的问题：这句话出自哪一页？模型是不是在编？读完怎么用？
我做了一个科研助手 ConGoRAG，把这三个问题做成一条可验证的闭环。"

### 00:25–01:05 痛点与定位

**画面**：技术文档封面/架构图（或 README 一句话定位）。

**旁白**：
"通用 RAG 只给文件名，不给页码；模型经常给出看起来像引用、其实对不上的编号；
而读完的笔记和综述，还得自己重新整理。ConGoRAG 在 PDF 解析、检索、生成、
写作四个环节都围绕'证据'设计：每个分块有页码和坐标，每个回答有引用校验，
每份草稿都能点回原文。"

### 01:05–01:40 架构总览

**画面**：架构图（放大到全屏）。

**旁白**：
"系统是四个进程：React 前端；Go 的 api 和 worker；Python 的 PDF 解析 sidecar；
数据层是 PostgreSQL 加 pgvector。写入侧解析论文、切分、向量化；读取侧做
向量加全文的混合检索，再交给模型流式生成。模型通过 BYOK 接入，密钥加密存在本地。"

### 01:40–02:30 模块一：解析与检索调试

**操作**：知识库页 → 展示 `1706.03762v1.pdf` 已就绪、434 分块、15 页；
下拉到「检索调试」，输入"训练用了多少块 GPU"，检索。

**旁白**：
"上传之后，sidecar 把 PDF 还原成块：每块带页码、归一化坐标、章节路径。
提问时先看检索这一层：这里同时给出融合分、向量分、词法分和页码——
中文查询靠 bigram 全文检索补足向量召回，两路结果用 RRF 融合。
这次命中第 8 页，向量 65%，词法也命中了。"

### 02:30–03:40 模块二：问答 + 引用跳原文（核心高光）

**操作**：新建会话 → 选择该知识库 → 输入"Attention 论文训练用了多少块 GPU？
训练了多久？"→ 等待流式完成 → 悬停引用角标 [4] → 点「在原文中查看」。

**旁白**：
"回答逐句带编号，引用是随流下发的。鼠标移到角标上，能看到它来自哪份文件、
第几页、哪一节。点'在原文中查看'——阅读器直接打开第 7 页，琥珀色框就是
这句话在原文里的位置。这就是可溯源：不是文件名，是第 7 页那一块。"

### 03:40–04:20 抗幻觉：引用校验 + 拒答

**操作**：回答下方「引用校验：2/2 句已溯源 · 通过」特写；随后在同一知识库问
"请解释量子纠缠与贝尔不等式的关系"，展示固定拒答文案。

**旁白**：
"回答下面这行绿色徽标不是装饰：后端逐句扫描引用编号，统计有多少句真的能对应上
资料。如果模型漏标，它会变成黄色'部分未溯源'。而检索不到证据时，系统根本
不调用模型，直接给出固定拒答——不可能编造。"

### 04:20–05:00 模块三：阅读器目录 + 整页翻译

**操作**：阅读器左侧目录点击「3.2 Attention」跳页；点右上「翻译本页」，
等右侧出现中文译文。

**旁白**：
"阅读器左侧是按层级缩进的章节目录，点哪一节跳哪一页。点'翻译本页'，
当前页的英文被整页翻译到右侧，公式、术语和引用编号都保留。"

### 05:00–05:30 模块五：引用图谱

**操作**：打开 `survey-related-work.pdf` 阅读器 → 左栏「参考文献（3）」，
[1] 高亮可点，点击跳到 1706.03762v1.pdf。

**旁白**：
"参考文献面板会把文献和知识库里已有的论文做匹配：survey 里的第一条
'Attention Is All You Need' 高亮显示，因为这篇论文就在当前知识库里，点一下
直接跳过去。这就是库内的引用图谱。"

### 05:30–06:10 模块六：写作 Copilot

**操作**：知识库页「写作 Copilot」→ 输入主题「Transformer 的注意力机制与训练效率」
→ 选「相关工作」→ 生成 → 滚动展示草稿 + 依据列表。

**旁白**：
"写综述时，选一个主题和体例，系统用检索到的证据生成草稿：每个事实句带编号，
下面列出所有依据，点页码就能回原文核对。草稿是可编辑的 Markdown，可以直接
粘进论文里继续改。"

### 06:10–06:40 模块四：Agent 检索 arXiv

**操作**：Agent 页面 → 运行「检索 Transformer 高效注意力机制的论文」→
展示 tool_call（`all:Transformer AND all:efficient AND all:attention`）与
返回的 DiNAT 等论文。

**旁白**：
"Agent 这边，模型会自己决定去 arXiv 检索：它生成了检索式，调用工具，
拿到真实论文的标题、作者、摘要和链接，再组织成回答。工具的每一步调用
都能在轨迹里看到。"

### 06:40–07:00 收尾

**画面**：回到架构图，字幕打出创新点。

**旁白**：
"总结一下：块级学术溯源、引用落地检查、确定性拒答、中文友好的混合检索，
再加上 arXiv、引用图谱和写作 Copilot，构成一个读、查、写一体的科研工作台。
代码、技术文档和在线演示都在提交材料里，谢谢观看。"
