演示路径建议：

1. 知识库 → PDF 学术解析验证 → 检索调试（看三路分数与页码）
2. 对话 → 提问"训练用了多少块 GPU" → 悬停引用角标 → 「在原文中查看」→ 第 7 页 bbox 高亮
3. 同一回答下方「引用校验」徽标；再问无关主题看固定拒答
4. 阅读器：章节目录、双语对照、划词/悬停翻译、参考文献
5. 知识库 → 写作 Copilot：完整论文框架 + Graphviz；CSV 可视化
6. 知识库 → 引用图谱 → 生成图谱/自动综述
7. Agent → arXiv 文献助手：运行检索，看 tool_call/tool_result
