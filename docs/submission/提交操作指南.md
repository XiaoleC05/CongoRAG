## 四、提交步骤（个人中心）

1. 登录赛事官网 → 个人中心 → 我的赛项 → 省赛作品提交；
2. 按表单填写作品名称、简介（可用 `docs/submission/README.md` 第一、二节）；
3. 上传技术文档 PDF、演示视频（或链接）；
4. 填写代码仓库地址与在线演示地址 + 口令；
5. **逐项检查后提交**；提交成功后截图存档（回执页 + 材料列表页）；
6. 把回执截图存入 `_record/提交回执/`，并更新本文件"已提交"状态。

## 五、提交后（评审期）

- 每天检查一次在线演示可用性（临时隧道方案尤其重要）；
- 关注个人中心/短信/QQ 群，确认是否有材料补交或评审通知；
- 评审期不改代码仓库主分支（评审看到的应该是 tag 对应的稳定版本）；
- 预指导反馈（若有）按官方口径处理：预指导分数是省赛保底分，可据此决定是否优化后最终提交。

## 附：可直接复制的作品简介（约 400 字）

ConGoRAG 科研助手是一个可溯源、抗幻觉的论文阅读与写作工作台，面向研究生与科研人员的
文献精读与综述写作场景。作品为 MIT 开源项目，当前 v6.0.0 主线覆盖完整科研链路：PDF 由
Python 侧车解析到块级别（页码、归一化坐标、章节路径、OCR/表格），回答中的每条引用都能
点回原文第 N 页并高亮对应段落；检索采用"向量 + 中文 bigram 全文 + RRF 融合 + 近重复抑制"，
并给出融合/向量/词法三路分数；抗幻觉采用三道闸门（逐句引用提示词、grounding 引用落地检查、
无证据固定拒答）；在此之上提供论文阅读器（目录/整页翻译/参考文献）、arXiv 检索 Agent、
引用图谱与写作 Copilot（相关工作/摘要/提纲草稿，逐句引用可回链）。系统为 Go + React +
Python 三进程架构，OpenAPI 契约驱动，Docker Compose 一键部署，本地优先 + BYOK。
仓库：https://github.com/XiaoleC05/CongoRAG（分支 main）。
