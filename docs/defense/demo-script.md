# 现场 Demo 脚本（7 分钟）

> 目标：在 7 分钟内把评分表 a–f 的证据动作全部演一遍。每个动作都配一句
> 这在评什么，避免变成功能罗列。演示前先 `make up && make migrate-up && make river-migrate-up`
> （或直接用已部署环境），准备：1 个含 3 篇 PDF 的知识库、1 个已跑过的 Agent。

| 时间 | 动作 | 评什么 |
| --- | --- | --- |
| 0:00–0:30 | 打开首页：一句定位「把论文读成证据」；点「进入演示」 | f 叙事 |
| 0:30–1:30 | 知识库详情：文档状态、分块数；点「检索调试」输入问题，展示 vectorScore / lexicalScore / RRF 三列 | a 检索、d 用例 |
| 1:30–2:30 | 对话页提问「训练用了多少块 GPU」：流式出字、citation 先于正文出现、grounding 徽标；点 [n] → 阅读器第 7 页 bbox 高亮；再问无关问题，展示固定拒答 | a 抗幻觉、e 流式 |
| 2:30–3:15 | 阅读器：章节目录跳转、双语对照滚动同步、划词翻译；缩到 390px 展示目录/翻译抽屉 | e 联动阅读、响应式 |
| 3:15–4:00 | 引用图谱：20 篇论文环形图，PageRank 基石节点；点节点跳阅读器；生成综述 + Future Work | b 创新（图谱） |
| 4:00–4:45 | 写作 Copilot：相关工作草稿，每个事实句带 [n]；点引用页码回原文；CSV 可视化生成 Mermaid/TikZ/Matplotlib + Caption | b/d 写作与可视化 |
| 4:45–5:30 | Agent 页：跑一次 arXiv 检索，展开执行轨迹（tool_call 参数与返回、耗时）；点取消再恢复一次运行 | a Agent 编排 |
| 5:30–6:15 | Prompt 审计页：任选 chat.system，切 v1/v2 看变更原因与指标，指向 SHA-256；说明采样参数本轮起真正生效 | a Prompt/Guardrails |
| 6:15–7:00 | 工程证据：`make check` / `make bench-gate` / `make bundle-check` 一条命令；打开 CHANGELOG 展示六轮版本；最后一句「全部可复现」 | c 工程 |

## 演示前检查

- 数据：知识库 ≥2（一篇含公式、一篇扫描件）、Agent run ≥3（1 个取消、1 个恢复过的）。
- 网络：模型 Key 可用；准备离线录屏兜底。
- 浏览器：1440×900，深色主题；另开一个 390px 窗口演示响应式。
- 计时：每个动作设 15s 缓冲；超时就跳到「工程证据」收尾。
