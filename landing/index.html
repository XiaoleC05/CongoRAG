把论文，
读成证据[1]。

上传一篇论文，问它问题。回答会给出页码和原文位置，点一下就回到 PDF 那一页。读、译、查引用、写综述，都在同一个工作台里完成。

01 / 解析

先把 PDF 拆成
能定位的块。

解析结果不是一段纯文本，而是带页码、坐标和章节路径的块。扫描件走 OCR，五百多页的教材也能进入同一条流水线。

  • v1 / v7 同时上传：按正文指纹发现重合，距离 6 时告警。
  • 版本差异：模型总结两版修订点，保留/覆盖由你决定。
  • 首页元信息：作者与机构单独成块，问“作者是谁”也有出处。
“没有证据时，它直接说不知道。”无证据拒答 · grounding 校验 · 引用落地检查
02 / 证据

答案和出处
一起出现。

检索先走两条路：向量召回语义相近的段落，中文 bigram 全文召回精确的词和编号，再用 RRF 合并。生成时每个事实句都带 [n]，回答结束后逐句检查引用是否落在资料里。

  • 页码范围：引用带 page / bbox / sectionPath，点开就是原文高亮。
  • 拒答：检索不到证据时返回固定说明，不调用模型。
  • 多篇对比：横向问题生成带引用的对照表。
03 / 图谱

顺着引用，
找到那篇基石论文。

参考文献标题与库内文档归一化匹配，聚合成有向图；PageRank 选出基石论文。再基于图谱生成领域综述和 Future Work，结合年份线索只保留仍然开放的方向。

  • 演示库 20 篇：Attention、BERT 系、ViT/Swin、T5、LLaMA 等。
  • 点节点回原文：图谱不是装饰，是阅读入口。
  • 综述可核对：材料不足时明确说明。
04 / 写作

读到的，
直接变成草稿。

写作 Copilot 根据知识库检索结果生成相关工作、摘要或完整论文框架；每个事实句带 [n]，引用列表的页码可以点回原文。它不替你编参考文献。

  • 完整框架：Abstract / Introduction / Related Work / Method / Experiments / Conclusion。
  • Graphviz：结构图脚本随框架一起给出。
  • 数据可视化：表格到论文图表，不用手写三套代码。
